# Catford Print Centre

A modern, responsive redesign of the Catford Print Centre website. The site preserves the existing product wording, product pages, pricing tables and quote options while presenting the range in a clearer, more accessible format.

The project contains the full multi-page legacy range, with 47 migrated legacy pages, two rebuilt artwork guides, the new home page and a complete service directory.

## Preview locally

Open `index.html` in a browser, or serve the folder with any static web server.

`generate-pages.py` is the migration utility used to build the styled legacy pages from the public Catford Print Centre source. Install `requirements.txt` before rerunning it.

## Deployment

The site is configured for GitHub Pages through the workflow in `.github/workflows/pages.yml`.

## Contact and ordering

Quote requests are prepared as an email to `web@catfordprint.co.uk`. Existing upload, guide, privacy and terms links continue to use the live Catford Print Centre services.
